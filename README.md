# Duwooo

Duwooo 是 macOS 上管理多個 AI 代理（Claude Code、Codex…）的桌面 App：多個任務在背景同時跑、任務之間互通、AI 操作瀏覽器與其他 App、自動填入密碼、排程、手機 App。

這個 repo **只放安裝檔**，不含程式碼。

## 下載與安裝

1. 到 [Releases](https://github.com/Jerry58321/duwooo-releases/releases/latest) 下載 `Duwooo-<版本>.dmg`
2. 打開後把 Duwooo 拖到「應用程式」
3. 第一次打開會引導你安裝 herdr，並登入 Claude Code 或 Codex
4. 怎麼使用：看 [使用教學](GUIDE.md)（App 裡也可以從選單列 **說明 › 使用教學** 打開）

- 支援 Apple 晶片與 Intel Mac，macOS 13 以上
- 已通過 Apple 公證；之後的新版會自動下載，重新啟動就會更新
- 隱私權：Duwooo 不收集你的資料，對話、檔案、密碼都留在你的電腦上
